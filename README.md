# Anime Requester

### Pour accéder au site, [Cliquez ici](https://paulmunoz14.github.io/Anime-Requester/).

## Description

Anime Requester est un projet web proposant à l'utilisateur de requêter une base de données d'anime via un formulaire.

Les recherches d'anime sont effectuées grâce à l'API Anime db [Disponible ICI](https://rapidapi.com/brian.rofiq/api/anime-db/playground).

## Technologies

- HTML5
- CSS3
- JavaScript
- API Anime db
- GitHub Pages

## Déploiement en local
Pour lancer le site en local, il faut cloner le dépôt GitHub puis servir les fichiers via un serveur local : le site utilise des modules JavaScript, ils ne fonctionnent pas en ouvrant `index.html` directement depuis le navigateur (`file://`).

### Avec Git

```
git clone https://github.com/PaulMUNOZ14/Anime-Requester.git
cd Anime-Requester
```

### Avec un serveur local
Il est également possible d'utiliser un serveur local, notamment avec l'extension Live Server de Visual Studio Code

1. Ouvrir le projet dans Visual Studio Code.
2. Installer l'extension **Live Server**.
3. Faire un clic droit sur **index.html**.
4. Sélectionner "**Open with Live Server**".
5. Le site s'ouvre automatiquement dans le navigateur à une adresse similaire à http://127.0.0.1:5500
